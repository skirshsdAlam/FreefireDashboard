# 🔥 Free Fire Dashboard Android Application 🔥

A complete, professional Android application for Free Fire game statistics and player information.

## ✨ Features

✅ **Beautiful Dashboard** - Modern UI with player statistics
✅ **Multiple Players** - 10+ players with detailed information
✅ **Leaderboard** - Top players ranking system
✅ **Player Details** - Click any player to see full statistics
✅ **Weapons Guide** - Complete weapon information
✅ **Map Guide** - Bermuda map locations and tips
✅ **Dark Theme** - Professional dark theme
✅ **Smooth Navigation** - Easy navigation between screens

## 📱 Screenshots

- Main Dashboard with player stats
- Player details with K/D ratio
- Leaderboard view
- Weapons guide
- Map information

## 🚀 Installation

1. Clone this repository
2. Open in Android Studio
3. Build and run on your device/emulator
4. Minimum SDK: 21
5. Target SDK: 33

## 🎮 How to Use

1. **Main Screen** - View player statistics
2. **Click Weapons** - See weapon guide
3. **Click Map** - View Bermuda map information
4. **Click Top Players** - See leaderboard
5. **Click Any Player** - View detailed player stats
